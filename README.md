# ETL

A Jupyter Notebook project for extracting, transforming, and loading data.

## Getting Started

1. Install Python and [JupyterLab](https://jupyter.org/) or Jupyter Notebook.
2. Clone the repository:

   ```bash
   git clone https://github.com/patience9kyalo/etl.git
   cd etl
   ```

3. Create a virtual environment and install the project dependencies:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   python -m pip install jupyter pandas
   ```

4. Start Jupyter:

   ```bash
   jupyter notebook
   ```

5. Open the notebook files in Jupyter and run the cells from top to bottom.

## Project Structure

- `*.ipynb` — Jupyter notebooks containing the ETL workflows and analysis.

## Usage

Update paths and configuration variables in the notebook before running it. If the workflow requires external data sources or credentials, provide them in a local, uncommitted environment or configuration file.
